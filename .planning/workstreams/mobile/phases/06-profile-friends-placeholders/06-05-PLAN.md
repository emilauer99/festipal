## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| App → Betriebssystem-Browser (SafeNow-Link) | Ein externer Aufruf verlässt die App; das Ziel bestimmt, wohin die Nutzenden geschickt werden. |
| Angemeldete Session → abgemeldeter Zustand | Der Abmeldepfad ist die einzige Stelle, an der eine Session auf einem geteilten Gerät beendet wird. |
| Gerätelokaler Override → gerendertes Farbschema | Eine gerätelokale Präferenz steuert die Darstellung aller Screens. |
