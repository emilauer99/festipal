<assumption_delta_decision>
## Singular → Plural: die Profil-Projektion

**Der Übergang:** Bis heute gibt es **eine** Projektion des Besucherprofils
(`visitorProfilePublicSchema`, alleiniger Produzent `MeService.getProfile`). Ab dieser Phase gibt
es **zwei**: eine Owner-View mit weiterhin genau einem Aufrufer und eine Fremd-View, die im Lauf
der Phase vier Aufrufstellen bekommt (D-04: Handle-Lookup, Suchtreffer, Anfragelisten,
Freundesliste).

**Das jetzt primäre Substantiv:** „ein Profil, wie es *jemand anderes* sieht" —
`visitorProfileForeignSchema` / `VisitorProfileForeign`.

**Entscheidung: `promote`.** Die allgemeine Repräsentation (Fremd-View) wird zur Basis, die
spezielle (Owner-View) wird zur benannten Variante darauf:

- `visitorProfileForeignSchema = visitorProfileSelectSchema.pick({ … sechs Felder … })`
- `visitorProfileOwnerSchema = visitorProfileForeignSchema.merge(visitorProfileSelectSchema.pick({ birthDate: true }))`

**Begründung (auf den Sachverhalt, nicht auf die Regel):** Beide Formen bleiben aus der
drizzle-zod-Basis komponiert, damit Pitfall 6 (nie handgespiegelt) gilt und ein Spaltenrename den
Typecheck bricht. Die Promotion kauft darüber hinaus **Default-Closed by Construction**: eine neue
Spalte auf `visitor_profile` erscheint in KEINER der beiden Sichten, bis jemand sie explizit
pickt — und wenn sie gepickt wird, ist der Unterschied zwischen „für alle sichtbar" und „nur für
mich sichtbar" genau eine Zeile Diff an genau einer Stelle. Die Alternative
(`add-alongside`, zwei unabhängig gepflegte `.pick()`-Listen) hätte dieselbe Drift-Erkennung, aber
keine sichtbare Ordnung: nichts im Code würde sagen, welche der beiden Listen die restriktive ist.
Gegen D-01 (genau zwei Stufen) spricht die Promotion nicht — sie kodiert D-01 sogar: es gibt
sichtbar eine Basis und genau eine Erweiterung, kein Platz für eine dritte Stufe ohne
ausdrückliche Änderung.

**Companion-Invariantentest:** Die Promotion allein verhindert keinen zweiten, ungeprojizierten
Pfad. Der Test, der genau das erzwingt (Contract-Walk über alle Router-Einträge plus
Quellcode-Singularitätsprüfung), gehört zu **Plan 07-05** und ist dort keine Kür: VIS-02 verlangt
ihn wörtlich.
</assumption_delta_decision>
