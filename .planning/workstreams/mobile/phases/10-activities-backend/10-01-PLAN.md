<assumption_delta_decision>
**Noun now primary:** *tag catalog entry* — `activity_tag`, scoped by a **nullable** `festivalId`
where `NULL` means "global catalog, curated by the platform admin" and a set value means
"festival-own custom tag" (ADR-017 §3).

**Decision: `promote`.** The generalized `activity_tag` becomes the **only** tag store; the
single-identity scaffold `tag` (tenant-scoped, `festivalId NOT NULL`) is removed rather than kept
alongside. This is not a fresh call — CONTEXT.md D-01 already decided *ersetzen, nicht migrieren*
on the grounds that the scaffold holds 0 rows, has 0 clients, and that ADR-017 names ActivityTag
the single tag store. Recorded here for the architecture ledger, not re-litigated.

**Second signal — required → optional:** `capacity` becomes nullable (`NULL` = unbegrenzt, D-08)
and the free-text `location` stays the anchor while the geo point is opt-in. Both land in plan
10-02/10-03; the anchor rule (freetext location is required reading, geo is additive) is recorded
there.

**Suggested invariant test (not required):** the effective-tag-list test in Task 3 —
enabled-global ∪ festival-own across two festivals — already encodes the generalized intent. No
separate invariant test is warranted.
</assumption_delta_decision>

**API.** Neues Verzeichnis `apps/api/src/activity/` mit drei Dateien nach dem Vorbild von

- `activity.service.ts` — `@Injectable()`, `constructor(@Inject(DB) private readonly db: Database)`. Eine Methode:
  `listEffectiveTags(festivalId: string, requested?: Locale): Promise<ActivityTag[]>`.
  Sie liest zuerst `festival.defaultLocale` für `festivalId`; findet sie das Festival nicht,
  liefert sie `[]`. Dann **eine** Abfrage: `from(activityTag)`,
  `leftJoin(festivalActivityTag, and(eq(festivalActivityTag.tagId, activityTag.id), eq(festivalActivityTag.festivalId, festivalId)))`,

  `.filter()` im JavaScript — der ARCHITECTURE-Anti-Pattern-Eintrag „ein Endpunkt plus
