<objective>
TRACER: wire ONE authenticated path end-to-end and prove it against the live dev API —
request an email-OTP, verify it into a sliding session, and reach exactly one protected
endpoint (`GET /api/v1/me`). This proves the whole load-bearing architecture (betterAuth
instance + emailOTP plugin + global AuthGuard + bodyParser:false re-application + /api/v1
vs /api/auth prefix coexistence + @Session on a ts-rest handler) before any expansion
endpoint is built. No other endpoints, no other call sites — one path, real error handling.

Purpose: catch an architectural dead-end after one commit, not after ten.
Output: a running auth-protected API with a green end-to-end smoke proof.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| client → /api/auth/* | Untrusted OTP request/verify input; better-auth self-manages auth, rate-limits, atomic consume |
| client → /api/v1/* | Protected-by-default; only a valid session cookie crosses into handler logic |
| API → email provider | Fire-and-forget send; provider outcome never gates the HTTP response |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-02-03 | Elevation of Privilege | global AuthGuard tagging | high | mitigate | /me inherits the global guard (no @AllowAnonymous); guard-tracer spec asserts 401 unauthenticated; only health is tagged anonymous |
| T-02-04 | Information Disclosure | OTP-send response timing | high | mitigate | `void otpEmailProvider.send(...)` fire-and-forget, always-success response by construction; send failures logged out-of-band only (D-01, Pitfall 9) |
| T-02-05 | Spoofing / Denial of Service | bodyParser:false wiring | medium | mitigate | AuthModule re-applies JSON parsing for non-auth routes; the OTP-verify POST body-parse half is proven by the smoke script; full two-POST proof consolidated in Plan 05 |
| T-02-06 | Elevation of Privilege | session model | high | mitigate | better-auth sliding session (expiresIn/updateAge), httpOnly signed cookie default, no custom refresh grant to misconfigure (D-02, Pitfall 10) |
</threat_model>
