| SecureStore ↔ app | Session token at rest (unchanged from Phase 3) |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-4-03-S | Spoofing | OTP send/verify | high | mitigate | No session established without a real authClient OTP round-trip (prohibition preserved); server owns OTP validity + rate limit (Phase 2, unchanged) |
| T-4-03-T | Tampering | username uniqueness (TOCTOU) | high | mitigate | DB lower(username) unique index → 23505 → 409; client 409 branch preserved, advisory availability never treated as authoritative (Pitfall 11) |
| T-4-03-I | Information Disclosure | session token storage | medium | mitigate | SecureStore only (Phase 3, unchanged); force-quit UAT confirms rehydration path, no token moves to MMKV |
| T-4-03-D | Denial of Service | OTP endpoint | medium | accept | better-auth built-in rate limiter (Phase 2); client surfaces 429 copy, adds no new send surface |
</threat_model>
