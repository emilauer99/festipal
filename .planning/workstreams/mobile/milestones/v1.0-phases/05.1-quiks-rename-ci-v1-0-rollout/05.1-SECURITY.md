## Trust Boundaries

| Boundary | Description | Data Crossing |
|----------|-------------|---------------|
| mobile app → API `/api/auth/*` | The Expo client's requests carry the app scheme as origin; better-auth's origin/CSRF check is the gate | Session cookie, OTP code, email address |
| OS deep-link handler → app router | An externally-supplied URL enters the app through the custom scheme and is replayed as a route | Untrusted route string |
| npm registry / lockfile → developer machine | `pnpm install` resolves and executes package lifecycle scripts | Third-party code, native binaries |
| developer machine → local Postgres container | Compose-published ports on the dev host | Local dev credentials, seed + test data |
| repo → version control | `.env` files must never cross this boundary | Secrets |
| `docs/quiks_CI.html` → repo source | An untrusted design-bundle file supplies literal colour/gradient/SVG numbers | Literal numeric values only |
| generator script → committed binary assets | A build-time script writes binaries that ship inside the app package | PNG launcher icons |
| device OS appearance setting → app render | External, attacker-uncontrolled signal that can leave surfaces unpainted if unhandled | `useColorScheme()` value |
| API/server error payloads → rendered error copy | The user's only signal that a security-relevant operation failed (OTP rejected, save conflict) | Error state, error copy |
| old app installation → test device | A stale build under the previous bundle ID with its own local storage | MMKV session/profile data |

## Accepted Risks Log

| Risk ID | Threat Ref | Rationale | Accepted By | Date |
|---------|------------|-----------|-------------|------|
| AR-01 | T-05.1-05 | Compose publishes Postgres `5432` and Mailpit `1025`/`8025` on `0.0.0.0`, not loopback — the plan's "bound to loopback" wording is factually wrong and is corrected here. The binding itself is deliberate and predates this phase (D-11, Phase 3): the stack exists so a real Android device on the LAN can exercise the full auth+festival flow, and the Mailpit OTP UI is documented as `http://<lan-ip>:8025`. Restricting to `127.0.0.1` would break device testing. Scope is dev-only on a single developer's machine; credentials are throwaway (`quiks`/`quiks`) and reach no hosted system — Neon and Railway are untouched. Residual exposure: anyone on the same LAN can read OTP codes from Mailpit and connect to the local DB. **Revisit before any shared/CI network or a second developer joins.** | Emil (gsd-secure-phase gate, 2026-08-11) | 2026-08-11 |
| AR-02 | T-05.1-06 | `docker compose down -v` destroys local seed/test data; recovery is `migrate` + `seed`, which ran in the same plan. Local dev data only. | D-13 | 2026-08-11 |
| AR-03 | T-05.1-14 | Icon generation runs at authoring time, not build or runtime; the PNGs are committed artefacts, so a generator failure cannot degrade the shipped app. | Plan 05.1-06 / UI-SPEC E2 | 2026-08-11 |
