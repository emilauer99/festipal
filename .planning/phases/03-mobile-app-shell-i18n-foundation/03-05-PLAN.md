### Note on festival fields (schema reality vs UI-SPEC)
The current `festivalSchema` (`packages/contracts`) exposes name/slug/locales — dates/place are
Phase-5 master data and are NOT in the schema yet. Render the festival NAME (always present) and omit
any optional line that is absent (UI-SPEC "partial" state) rather than rendering blank. Do not invent
date/place fields this phase.
