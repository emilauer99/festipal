## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| concurrent writers -> visitor_profile.username | Two requests may race to claim the same (case-variant) username |
| global Account (user) -> visitor_profile | 1:1 identity link; must not become a festival-scoped bridge |
| packages/db -> packages/contracts | Base schemas cross the package edge; a hand-mirror here would silently drift |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-UN | Spoofing | username case-variant duplicate / race | high | mitigate | DB-level UNIQUE INDEX ON lower(username) — race-proof at the schema layer; asserted present in migration SQL (the app-layer 23505 catch is Phase 2) |
| T-01-DR | Tampering | Contract/DB schema drift reopening a validation gap | high | mitigate | contracts composes on the drizzle-zod base (no hand-mirror); drift proof asserts a column rename breaks contracts typecheck |
| T-01-PII | Information Disclosure | socials/socialsVisibility exposed before a visibility policy exists | medium | mitigate | contracts read schema picks only accountId/username/displayName/avatar; reserved fields omitted |
| T-01-XT | Information Disclosure | visitor_profile bridging global identity to a tenant scope | high | accept | visitor_profile carries no festivalId; the global<->tenant link is my_festival (Plan 03) — no bridge introduced here |
