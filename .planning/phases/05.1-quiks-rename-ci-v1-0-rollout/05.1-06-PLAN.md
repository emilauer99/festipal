<objective>
Build the quiks brand mark once and use it twice: as a runtime `react-native-svg` component and as
the source of the six regenerated app-icon PNGs, replacing the Expo placeholder assets.

Purpose: D-07 requires real icons, and the CI's mark is a text glyph with a gradient fill plus a
solid dot — not a bitmap. One geometry module keeps the runtime render and the raster provably
identical instead of two drifting copies.
Output: a shared geometry module, a font-gated RN component, a committed generator script, six
regenerated PNGs, and Android's adaptive-icon background on Papier.

Requirement-ID substitution (visible, recorded): no REQ-IDs exist for this phase; ADR-023 is the
traceability anchor for the CI work (see plan 05.1-01 objective for the full note).

**Flagged planner assumption — surface it, do not bury it.** UI-SPEC row E2/populated states the
mark is built "from one SVG construction at both the splash size and the 1024px icon raster", and
row E2/loading describes a runtime font-readiness concern that only exists if the glyph renders at
runtime. CONTEXT.md D-02, however, defines the splash as the `quiks.` wordmark TEXT and says
nothing about a mark above it. This plan therefore mounts `WordmarkGlyph` on the splash above the
wordmark text as the interpretation that satisfies both documents, and the plan 05.1-07 device
checkpoint asks the developer to confirm or reject that single mount. If rejected, the component
and the generator stay and only the mount is removed — a one-line change. This is recorded here
rather than silently resolved in either direction.

**Recorded decision (Claude's Discretion — icon rasteriser):** `@resvg/resvg-js` at the version
audited in `05.1-RESEARCH.md` § Package Legitimacy Audit (verdict OK / Approved: real registry
history, ~2.29M weekly downloads, source repo `github.com/yisibl/resvg-js`; no [ASSUMED], [SUS] or
[SLOP] verdict, so no legitimacy checkpoint is required). It is a devDependency only: the PNGs are
committed, so no build path depends on it. Reversibility: `reversible` — swapping the rasteriser
changes one script and re-runs it.
</objective>
