## Recorded decisions (Claude's Discretion areas from CONTEXT.md)

**Theme access pattern — decided: pure resolver in `apps/mobile/lib/theme.ts` + Context in
`apps/mobile/lib/theme-context.tsx`, NOT in `packages/ui`.** Rationale: `packages/ui` today has no
`react`/`react-native` dependency at all, ships a tsup ESM+CJS build consumed from `dist/`, and has
exactly one consumer (`apps/admin` does not exist — ADR-018 is still TBD). Putting a React provider
there would add peer dependencies, JSX build configuration and a build-order coupling for Metro,
in exchange for a second consumer that does not exist. The app already has the exact sibling
pattern for this shape — a pure node-importable module plus a Context file (`lib/fonts.ts` +
`lib/fonts-context.tsx`) — and the mobile Vitest runner is node-env scoped to `lib/`, which is
precisely where the Wave-0 validation gap wants the resolver to live. `packages/ui/src/tokens.ts`
remains the single source of token VALUES. Reversibility: `reversible` — moving the two files into
`packages/ui` later is a mechanical import change behind an unchanged public shape.

**Status colours — decided.** `warning` is confirmed as Amber `#FFC53D`, identical to `secondary`:
the CI frames Amber as the colour of hints/notices, so the double duty is intentional and pairs
with `textOnSecondary` on filled surfaces. `success` is **confirmed unchanged at `#8FDA3B`**, and
this closes the UI-SPEC checker's non-blocking Dimension-3 FLAG. Reasoning, stated explicitly
because the hue originates in the Limette ramp that D-11 deletes: D-11 removes Limette as a *brand*
colour; status colours are outside the CI entirely (`docs/brand/quiks-ci-v1.md` defines none), the
hue is never used as a brand or surface colour, and the UI-SPEC's measured light-mode variant
`successText #527C22` (4.52:1 on Papier) is already computed against this exact hue — changing it
would invalidate a measured contrast value with no CI mandate to replace it. Reversibility:
`reversible` — one token value in one file. Flagged for the device walk-through in plan 05.1-07: if
the green reads as leftover branding next to Beere/Amber, it is a one-line follow-up.
