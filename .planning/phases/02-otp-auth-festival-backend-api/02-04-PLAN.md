| Boundary | Description |
|----------|-------------|
| session → POST /festivals/:id/save | Authenticated but gate-less; writes only the caller's my_festival row |
| seed script → DB | Out-of-request-cycle write using the unpooled URL; idempotent, no secrets |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-02-10 | Elevation of Privilege | gate-less save mis-scoped | high | mitigate | save writes my_festival keyed by session.user.id; no client-supplied visitorId; browse (unscoped list) and my-festivals (caller-scoped) are two distinct contracts, never one + .filter() (Pitfall 4) |
| T-02-11 | Tampering | duplicate save rows | medium | mitigate | onConflictDoNothing on the (visitorId, festivalId) composite PK; save-idempotency.spec proves one row after repeat saves |
| T-02-12 | Denial of Service | save of unknown festival | low | mitigate | Existence check returns a clean 404, no orphan my_festival row (FK would also reject) |
</threat_model>
