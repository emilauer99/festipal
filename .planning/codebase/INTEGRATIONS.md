# External Integrations

## APIs & External Services

**Email OTP Delivery (Optional):**
- **Resend** - Email API for passwordless OTP delivery
  - SDK/Client: `resend` v6.18.1 (`apps/api` dependency)
  - Auth: `RESEND_API_KEY` environment variable (optional)
  - Usage: `apps/api/src/auth/email/resend-otp-email-provider.ts`
  - Status: Env-gated, dormant Phase 2 (not required for MVP with console dev transport; activation is an env-var flip when real inboxes needed)
  - Sender: `festipal <onboarding@resend.dev>` (Resend onboarding domain)
  - Delivery: Fire-and-forget pattern (never await email before returning OTP response to prevent timing attacks)

## Data Storage

**Databases:**
- **PostgreSQL 18** via Neon (serverless, managed)
  - Type: Postgres 18 (latest stable, version fixed per Neon project)
  - Provider: Neon (`https://neon.tech`)
  - Region: AWS Europe Frankfurt (`eu-central-1`) — co-located with Railway backend and DSGVO-compliant for EU festival data
  - Connection: Pooled (pgBouncer) for serverless/edge access via `DATABASE_URL` (standard pooled connection string)
  - Direct Connection: `DATABASE_URL_UNPOOLED` for migrations (drizzle-kit) and integration tests (unpooled avoids pooler incompatibilities)
  - Client: Drizzle ORM (`drizzle-orm` v0.45.2) + `postgres` v3.4.9 driver (connection pooling with `prepare: false` for pgBouncer safety)
  - Schema Location: `packages/db/src/schema/` (TypeScript-first, snake_case SQL casing)
  - Migrations: `packages/db/drizzle/` (auto-generated by `pnpm --filter db db:generate`)
  - Configuration: `packages/db/drizzle.config.ts` (Drizzle Kit config, uses DIRECT unpooled URL for migrations)
  - Tables: `festival`, `user`, `session`, `account`, `verification` (auth schema from better-auth), `tag`, `tag_translation`, `visitor_profile`, `my_festival`, `locale` (enum)

## Authentication & Identity

**Auth Provider:**
- **better-auth** 1.6.25 - Self-hosted TypeScript authentication system
  - Implementation: NestJS module via `@thallesp/nestjs-better-auth` v2.7.0
  - Database: Drizzle adapter pointing to PostgreSQL (Neon)
  - Auth Tables: `user`, `session`, `account`, `verification` (managed by better-auth + drizzle adapter)
  - Primary Method: **Passwordless Email OTP** (email-otp plugin)
    - OTP Length: 6 digits
    - Expiry: 5 minutes
    - Resend Strategy: "reuse" (extends same code expiry on resend, not "rotate" which invalidates on resend)
    - Send Strategy: Fire-and-forget (OTP request endpoint always reports success regardless of delivery outcome)
  - Sessions:
    - Duration: 90 days (sliding session)
    - Update Age: Every 24 hours (refresh session on activity)
    - Refresh Strategy: No refresh-token grant (session expiry → re-authenticate via OTP)
  - Configuration: `apps/api/src/auth/auth.instance.ts` (singleton, constructed at import time)
  - Module: `apps/api/src/auth/auth.module.ts` (wraps `@thallesp/nestjs-better-auth` with body parser re-application for non-auth routes)
  - Admin Routes: `/api/auth/*` (self-managed by better-auth, always anonymous-accessible)
  - Email Transport:
    - Dev: Console output via `apps/api/src/auth/email/dev-otp-email-provider.ts` (logs OTP to stdout + `.otp-dev-transport.local.json`)
    - Production: Resend API via `apps/api/src/auth/email/resend-otp-email-provider.ts` (env-gated on `OTP_EMAIL_TRANSPORT=resend` + `RESEND_API_KEY`)
  - Secret: `BETTER_AUTH_SECRET` environment variable (required at runtime, never optional)

**Planned Auth Extensions (Post-MVP):**

## Environment Configuration

**Required Environment Variables:**
- `DATABASE_URL` - Neon pooled Postgres connection string (required)
- `BETTER_AUTH_SECRET` - Email OTP signing secret (required)
- `PORT` - API listen port (optional, default: 8081)

**Optional Environment Variables:**
- `BETTER_AUTH_URL` - Auth callback URL (default: http://localhost:8081)
- `DATABASE_URL_UNPOOLED` - Neon direct connection for migrations (recommended for production CI)
- `RESEND_API_KEY` - Resend API key (optional, enables production email delivery)
- `OTP_EMAIL_TRANSPORT` - Transport selection ('dev' or 'resend', default: 'dev')

**Secrets Location:**
- Development: Root `.env` file (git-ignored, not in repo)
- Railway: Railway environment variables dashboard (secure, not in code)
- CI/CD: GitHub Actions secrets (planned, not yet configured)
- **No secrets in repo** - enforced via .gitignore and ADR-010

**Load Strategy:**
- Backend: `apps/api/src/config/env.ts` loads and validates via Zod schema at startup
- Database: `packages/db/drizzle.config.ts` reads `DATABASE_URL_UNPOOLED` or fallback `DATABASE_URL` for migrations
- Fail-fast: Missing required env vars throw during bootstrap, preventing silent failures

## Rate Limiting & Abuse Prevention

**Email OTP:**
- better-auth default rate limiter: 3 OTP requests per 60 seconds per source (IP/email)
- Strategy: Fire-and-forget (never reveal rate limit to client, always report success)
- Test Impact: Integration tests serialized (fileParallelism: false) to avoid concurrent OTP requests tripping rate limiter

**Database Connections:**
- Neon connection pool: Limited concurrent connections (auto-scales to zero when idle)
- Pooler: pgBouncer (30-second idle timeout typical) — test setup includes reconnect resilience
